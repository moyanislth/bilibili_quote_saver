# Bilibili Quote Saver

一个面向 B 站视频观看场景的浏览器插件。

当用户想摘录一段话时，不再需要暂停、回放、手打，而是直接用快捷键开始记录，结束时自动汇总这段时间内的字幕。

## 完整功能

- **字幕录制** -- 快捷键一键开始/停止录制视频字幕，自动汇总时间区间内的所有字幕
- **30 秒回溯** -- 开始录制时自动包含前 30 秒的字幕，不会错过来不及记录的开头
- **B 站 API 集成** -- 自动从 B 站 API 获取完整字幕文本，比纯 DOM 提取更准确、更完整
- **Live 直播支持** -- 支持 live.bilibili.com 直播间的弹幕/字幕提取
- **多语言字幕** -- 支持中文、英文、日文等多语言字幕偏好选择
- **实时预览** -- 录制时在弹窗中实时滚动预览捕获的字幕
- **内联编辑** -- 双击字幕或标签即可直接编辑，回车保存
- **标签系统** -- 为每条收藏添加自定义标签，点击标签可筛选
- **搜索** -- 实时搜索字幕内容，支持高亮匹配
- **排序** -- 按时间（最新/最早）或按视频名称排序
- **置顶** -- 将重要收藏固定到列表顶部，跨排序保持
- **导出** -- 支持 JSON / TXT / Markdown 三种格式导出
- **导入** -- 支持 JSON 格式导入，自动跳过重复 ID，超出上限时保留最新
- **键盘导航** -- J/K 键上下切换卡片，Enter 复制，Delete/Backspace 删除
- **大列表优化** -- 超过 30 条时分批渲染，保持弹窗响应流畅
- **数据校验** -- 读取时自动校验每一条数据的完整性，跳过损坏条目
- **存储管理** -- 显示 storage 已用量，接近上限时自动发出警告
- **会话保护** -- 页面切换或导航时自动中断录制，防止跨视频数据混入
- **智能引导** -- 页面无字幕时给出操作提示，录制中显示悬浮指示器

## MVP 范围

- 运行在 `Chrome / Edge` 的 `Manifest V3` 插件
- 识别 B 站视频页并读取当前视频基础信息
- 尝试从页面可见字幕区域提取实时字幕
- 通过快捷键开始/停止记录字幕片段
- 使用 `chrome.storage.local` 本地存储收藏记录
- 在插件弹窗中查看、复制、删除和回跳收藏内容

## 当前实现

- 快捷键：`Ctrl+Shift+S`（Mac 为 `Command+Shift+S`）
- 交互方式：
  - 第一次按下：开始记录当前时间点之后的字幕（含前 30 秒缓冲）
  - 第二次按下：停止记录，并汇总这段时间内出现的字幕
  - 也可在弹窗中点击”开始记录/停止并汇总”按钮
- 收藏字段：
  - `id` / `text` / `mode` / `lineCount`
  - `videoTitle` / `videoUrl` / `jumpUrl`
  - `timestampSec` / `timestampLabel`
  - `endTimestampSec` / `endTimestampLabel`
  - `createdAt` / `tags` / `pinned`
- 弹窗功能：
  - 浏览、搜索、排序、标签筛选
  - 复制字幕 / 复制完整信息 / 复制时间戳链接
  - 双击内联编辑字幕和标签
  - 置顶收藏、删除单条、清空全部
  - JSON / TXT / Markdown 导出，JSON 导入
  - Live 录制实时预览
  - 存储用量显示和容量警告
- 录制功能：
  - 自动从 B 站 API 获取完整字幕（回退到 DOM 提取）
  - 30 秒 retroactive buffer，开始录制即自带上下文
  - 字幕去重与智能合并（重叠检测、标点清理）
  - SPA 页面导航自动检测与录制中断
  - Live 直播弹幕/字幕提取
  - 页面关闭前自动保存

## 本地加载

1. 打开浏览器扩展管理页
2. 开启”开发者模式”
3. 选择”加载已解压的扩展程序”
4. 选择 `extension` 目录

## 使用方式

1. 打开任意 B 站视频页
2. 确保视频存在可见字幕
3. 播放到想开始摘录的位置时，按 `Ctrl+Shift+S`
4. 继续观看，插件会在后台记录这段时间出现的字幕
5. 到结束位置后，再按一次 `Ctrl+Shift+S`
6. 页面右上角会提示”已停止并汇总字幕”
7. 点击插件图标，在弹窗中查看这段字幕汇总

## 已知限制

- 依赖页面现有字幕或 B 站 API 字幕；没有字幕的视频暂不支持
- B 站页面结构如果变化，字幕选择器可能需要更新
- 当前只做本地保存，未实现账号同步与 AI 清洗
